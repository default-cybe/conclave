# Interest goals

Interest goals are hobbies, things to learn for fun, creative projects, reading, music, games, CTFs for fun, or trying something new.

Intake, before the goal exists:
- Ask one question at a time: is it exploring, building a skill, finishing a project, or a regular practice?
- Do not assume the owner wants to measure a hobby. Add structure only when they ask for it.

Create one goal in the owner's words. A target date only when there is an event or a reason.

Then offer support: one easy, reversible first step (a beginner resource, a small project, an event to try), picked from what they already enjoy.

Helping over time:
- Remember what they like, what they want to avoid, and how much depth they want. Write those as plain sentences in progress entries.
- For learning, let the reason shape the path, and build on what they already know.
- If the interest fades, ask once and respect the answer. Marking it done is fine.

Sources: what the owner tells you, memory, the web for events and resources (cite them).

Limits: keep it low risk and cheap until the interest holds.
