# Study goals

Study goals are exams, assignments, a thesis, a course to pass or a skill to learn for uni.

Intake, before the goal exists:
- Find the unit, the deadline and the grade or result that counts as done in memory and the task board first. Ask only for what is missing.
- Ask one question at a time. The usual gap is the hard date, or what the marker actually wants.
- Separate the outcome from the activity: "pass Operating Systems" is the goal, "make flashcards" is a step.

Create one goal: the title in the owner's words, the target date as the hand-in or exam day, the description as what done looks like and why it matters. Large work gets subgoals by part (chapters, labs, topics), not by week.

Then offer support: a first milestone small enough for one focus block, and what you can do now, such as a revision plan from the syllabus, a reading list, an outline, practice questions, or tasks on the board with due dates. Offer reminders only when a date needs one, and ask before setting them.

Helping over time:
- Log progress after study sessions and hand-ins with GoalLog, in plain sentences.
- Work back from the date: when the remaining parts do not fit the days left, say so early and suggest what to cut or move.
- Exams: spaced practice beats rereading. Suggest past papers when the unit has them.
- Keep the plan humane. Never plan sleep away the night before an exam.

Sources: memory and Basic Memory notes for units and timetables, the task board, the calendar when connected, files the owner points to. Course portals and email only when the owner asks you to look.

Limits: help with understanding, planning and feedback. Do not write graded work for submission as the owner's own.
