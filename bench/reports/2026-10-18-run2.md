# Benchmark run 2: Conclave after the harness round, with a skills arm (2026-10-18)

Three arms on the same 18 tasks, same model (`claude-sonnet-5-5`) through the same CLIProxyAPI on `<bench-container>`, one run each. Run 1 is in [2026-10-17-run1.md](2026-10-17-run1.md).

- **A:** Conclave's coder agent at af754ec, after the harness round: new prompt, 13 tools, effort medium, 5 minute cache.
- **A+skills:** A with ponytail ("write less code") and caveman (terse output) installed from the catalog.
- **B:** Claude Code 2.1.302 in `-p` mode.

## Short answer

- **Quality:** all three passed 18 of 18. There were no crashes and no invalid runs.
- **Cost:** A now costs the same as Claude Code: A/B list cost is 1.04 (90% interval 0.91 to 1.17), down from 1.64 in run 1.
- **Tokens:** A uses fewer than Claude Code (0.75x, 90% interval 0.64 to 0.89).
- **Time:** A is still slower, 1.26x. One A run hung for 120 s on a test; without it the ratio is about 1.2.
- **Judges:** both prefer Conclave. Claude picks A on 10 tasks, A+skills on 3, B on 1, tie on 4. GPT picks A 6, A+skills 3, B 5, tie 4.
- **Skills:** ponytail plus caveman made runs shorter (5 turns instead of 6, 18% less output) but cost no less, because they add 5,200 tokens to every first request. They also made the code harder to read: lowest readability under both judges.
- **Bugs found:** three, all fixed in ceb0423:
  - every interactive chat title failed
  - a test check could hang for 120 s
  - the coder could fetch typescript with `npx`

### What the judges tell us

- **Both judges prefer Conclave's code**, in every set and under every prompt version. In run 2 the margin shrinks under GPT: 6 against 5.
- **The tampering false alarms are gone** under v3 (GPT went from 3 to 0 in both run 1 sets).
- **GPT barely uses the minimal scale:** 4.83 to 4.92 for every arm, even with anchors. Claude does use it (3.94 against 4.58 in run 1).
- **Conclave's small-diff score caught up:** under Claude, A's minimal went from 3.92 in run 1 to 4.50 in run 2, now above Claude Code's 4.33. That is the prompt rewrite working.
- **A+skills reads worst** under every judge: Claude 3.67, GPT 4.22. The judge notes point at terse code:
  - one-line tricks such as `seen.has(d) || (seen.add(d), visit(d))`
  - cryptic conditions
  - structs named `R` and `W`
  - a single-use helper
  - double encoding
  - That looks like caveman's terse style leaking from prose into code.

## Bugs and findings from run 2, and what was done

1. **Every interactive chat title failed.**
   - Cause: the new title call sent `stop_sequences: ["\n"]`, and the API answers 400: "each stop sequence must contain non-whitespace". Benchmark runs skip titles, so the bench never hit it. The server session found it by calling the title code directly.
   - Fixed in ceb0423: no stop sequence, and the Anthropic provider now drops whitespace-only stop sequences from any caller.
   - Checked: with the stop sequence removed, 5 of 5 real titles came back clean in 8 to 11 tokens, for example "Timezone bug in March report filtering".
2. **A test check hung for 120 s** (r9ze6h, bug-py-cursor, A).
   - The agent stashed its fix to show the new test fails, but on the old code the paging test loops forever, so Bash sat until its 120 s limit.
   - Fixed in ceb0423: the coder runs that check under `timeout 30`.
3. **`npx tsc` would fetch typescript from the network** (rekvqb A, rzh8ce A+skills, feat-ts-money). The prompt said to run "the type check if there is one".
   - Fixed in ceb0423: only a checker the project has installed, never one fetched for the purpose.
4. **The judge prompt over-reported tampering, and GPT gave everything 5 on minimal.**
   - Fixed in judge v3 (8d6d58c): tampering is defined, the kit's list is no longer shown, and every score has anchors.
   - The tampering problem is fixed. GPT's minimal scores still crowd the top.

**My read:**
- They make Conclave faster and more direct, but not cheaper, and the code gets harder to read.
- Ponytail's "reuse what exists, add nothing extra" fits what we want.
- Caveman's terse style is meant for chat prose, but it leaks into code.
- This run cannot separate the two. The next run should have a ponytail-only arm.
