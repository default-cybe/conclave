# Harness improvement: tool diet (PR #133), 2026-10-27

> **What was compared:** Conclave main before the tool diet (baseline e5e539ac, the Harness² candidate from [2026-10-27-h2-bugs.md](2026-10-27-h2-bugs.md)) against the tool diet (candidate d8429b69, PR #133, merged as 1f38ca53 and shipped in v0.4.42). Arm A (Conclave) only, through `bench/improve.ts`. Not Conclave vs Claude Code.
> **Model:** claude-sonnet-5-5 (requested and served). **Tasks:** the 6 bug tasks (bug-ts-cents, bug-ts-timezone, bug-ts-config, bug-py-retry, bug-py-utf8, bug-py-cursor). **Repeats:** 2, seed 1, 12 runs per arm, all counted. No judge.
> **Route:** hub gateway (`http://127.0.0.1:7717/gw/p/cliproxy`) to CLIProxyAPI on the owner's subscription, so list cost is accounting only, not money spent.
> **Raw results:** were in `bench-cand/bench/results/tool-diet-{baseline,candidate}/` (comparison.md, summary.md, summary.json, results.jsonl, runs/) in a temporary worktree on the hub. They are not kept in git. Every number below is copied from those files or from the PR #133 body.
> **Caveats the sources state:** both arms passed 12/12, so improve.ts says "keep baseline" (its rule looks only at pass rate); two repeats per task are too few to separate the per-run median from turn-count noise, so the median is flat; cost figures exclude doctor preflight requests; the proxy adds a few input tokens to every request and other load on the server was not controlled.

## What changed (from the PR #133 body)

- The coder's `disallowedTools` also lists CalendarList, CalendarFreeBusy, CalendarEvent, MailDraft, PlaceSearch, PlaceDetails, Directions and MapImage. Delegate, ShareFile and ConclaveHelp stay.
- In a Code session the platform card leaves out "Where things are in the app", the Settings lines, and the accounts and models line.
- Chat and the assistant still get every tool and the full card.

## improve.ts comparison (copy of tool-diet-candidate/comparison.md)

- Baseline: a worktree at e5e539ac; candidate: a worktree at d8429b69 (both temporary, removed).
- Model: claude-sonnet-5-5; tasks: bug-ts-cents, bug-ts-timezone, bug-ts-config, bug-py-retry, bug-py-utf8, bug-py-cursor; repeats: 2; seed: 1.
- Decision: **keep baseline**. Human review only; no merge or deploy.
- Hidden tests: 12/12 paired; 0 improved; 0 regressed.
- Baseline own tests (fail start/pass final): 10/12; regression gate proven: 10/12.
- Candidate own tests (fail start/pass final): 10/12; regression gate proven: 10/12.
- Recorded run list cost: $1.97 / $5.00 cap. The cap and reported spend exclude doctor preflight model requests (one per started set); doctor exposes no usage or cost.
